**말로 읽을 때 고칠 표현**

위 표의 수정과 함께, 어색하거나 추상적이거나 호흡이 긴 표현을 모두 모으면 다음과 같습니다. 일반적인 합니다체 자체를 AI투로 보지는 않았습니다.

**A의 사실관계 위험**

- **20쪽 — “학습시킨 AI가 이상이 있는지, 고장까지 시간이 얼마나 남았는지 판단합니다.”** 차량에서 남은 시간 예측까지 검증했다는 인상을 줍니다. 확인 전에는 ‘판단하는 구조’로 설명해야 합니다. “바로 찾을 수 있었습니다”도 실제 확인 성과를 추가합니다.
- **21쪽 — “20분쯤 AI가 먼저 이상을 표시했고 … 실제 고장선보다 7분 정도 앞섭니다.”** 실제 기록인지 확인되지 않았고, 무엇이 7분 앞서는지도 모호합니다. 탐지 표시는 약 7.5분, 기준선 통과는 약 3.5분 앞섭니다.
- **21쪽 — “이만큼 여유가 있으면 인버터나 모터가 상하기 전에 손을 쓸 수 있습니다.”** 그래프의 시간 차이가 실제 대응 가능 시간을 보장하지는 않습니다. 손상 전 대응이라는 목표로 낮춰야 합니다.
- **22쪽 — “열교환기에 때가 끼거나 배관이 좁아지는 고장은 진동으로는 잘 안 잡힙니다.”** 제공 자료로 입증되지 않은 일반화입니다. “정상일 때 나와야 할 값은 물리 계산으로 미리 알고 있으니”도 설비별 조건과 보정 필요성을 생략합니다.
- **22쪽 — “유량, 압력, 온도 차이로 … 직접 잽니다.”** 경쟁 우위 슬라이드의 제안 구성과 차량에서 확인된 수온·유량 측정을 섞습니다. 산업용 설계 설명인지 현재 구현 설명인지 구분해야 합니다.
- **23쪽 — “구독료를 월 10만 원까지 낮췄습니다. 경쟁사는 보통 월 30만 원에서 50만 원을 받습니다.”** 실제 판매가격 확정과 시장 전반의 통상가격처럼 들립니다. “월 10만 원으로 책정했습니다”, “표의 비교 대상은…”이 안전합니다.
- **24쪽 — “저희가 직접 만난”, “경고 값으로만”, “비용만 맞으면 … 답했습니다.”** 인터뷰 방식, 유일한 점검 수단, 가격만이 도입 조건이라는 내용은 지침에 없습니다. 인터뷰에서 확인된 범위로 줄여야 합니다.
- **25쪽 — “3년 차에는 … 돌아섭니다.”** 가정에 따른 전망입니다. “예상했습니다”로 바꾸고 반올림한 금액에는 ‘약’을 붙입니다. “그때까지 필요한 자금”은 전체 자금 수요보다 **누적 적자를 메울 금액**으로 설명하는 편이 정확합니다.
